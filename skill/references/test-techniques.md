# 场景与方法选择

仅在设计场景、选择 Oracle 或常规样例不足时读取。本文件提供方法，不增加强制测试数量或质量门禁。

| 对象 | 可选手段 | 检查重点 |
| --- | --- | --- |
| 枚举、条件、边界 | 表驱动、参数化、边界值 | 输入能区分关键分支，不只是多个近似样本 |
| 编解码、集合、计算 | 性质测试、独立参考模型 | 性质有契约依据，不复制被测算法；反例可复现 |
| 队列、幂等、状态机 | 操作序列、状态模型 | 重复、取消、恢复与跨步骤不变量 |
| 解析器、不可信输入 | Fuzz、非法字节及实际字符域 | 可控预算、最小失败样本与固定回归 |
| 高风险逻辑 | 局部变异测试、错误版本对照 | 断言能识别关键错误，解释等价变异 |

准备行为表：目标行为 → 初始状态/输入 → 依赖结果 → 正确预期及依据 → 观察方式。简单逻辑无需全部方法；无法判断预期时先澄清，不能靠增加样本掩盖 Oracle 缺失。

对遗留行为的刻画测试应说明用途是兼容性保护；不能将未经确认的当前行为当作需求正确性证明。无法运行原错误版本时，保留回归用例并注明敏感性证据未完成。
